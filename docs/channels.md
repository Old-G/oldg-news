# Каналы Radar: какие Telegram-подписки читать

Страница со всеми Telegram-подписками и переключателем у каждой:
**https://claude.ai/artifact/NmwQk8j2SDyQEj3drN5RBC**

Страница приватная: открыть её может только Глеб, под своим аккаунтом claude.ai. Ссылка в публичном репозитории ничего не раскрывает.

## Что на странице

У каждого канала:
- **постов** — сколько Radar забрал за 7 дней;
- **вкус** — средняя похожесть его историй на профиль вкуса (у отобранных в дайджест обычно 0.5+);
- **близко** — истории с похожестью от 0.45;
- **в заметки** — сколько раз из него пересылали в канал заметок и когда последний раз.

Фильтры: «Предлагаю выключить» (ни одной пересылки и вкус ниже 0.43 или ни одной близкой истории), «Ты пересылал в заметки», «Молчат неделю», «Выключены».

Переключатель сохраняется сразу — в базу самой страницы (коллекция `choices`, по документу на канал: `{enabled, title}`). В Radar изменения попадают, только когда их применят (ниже).

## Как поменять набор каналов

1. Открыть страницу, переключить нужное.
2. Сказать Claude в этом проекте: «примени выбор каналов». Claude читает `choices` (ArtifactData, `list`) и выставляет `sources.enabled` для этих id на сервере. Первым — один канал, потом остальные; в конце сверяет число включённых с выбором на странице.
3. Выключенный канал не читается со следующего `fetch`; уже собранное остаётся в базе.

Откат применения 15.10.2026 (27 каналов оставлено, 144 выключено): прежнее состояние лежит в таблице `sources_enabled_backup_20261015`:

```sql
update sources s set enabled = b.enabled from sources_enabled_backup_20261015 b where b.id = s.id;
```

## Как обновить цифры на странице

Цифры на странице — снимок на день публикации. Чтобы пересобрать её из базы:

```bash
ssh beget 'cd /opt/radar && docker compose run --rm -T worker python -m jobs.channels_page' > .local/radar-channels.html
```

Затем Claude публикует `.local/radar-channels.html` на тот же адрес (Artifact tool, `url` выше, `capabilities: {"db": {}}`). Сделанный выбор (`choices`) при этом сохраняется.

Шаблон страницы — `tools/channels_page.html`, данные подставляет `jobs/channels_page.py`. Готовая страница с данными лежит только в `.local/` (в `.gitignore`): список подписок и пересылок — личный, в публичный репозиторий не идёт.
