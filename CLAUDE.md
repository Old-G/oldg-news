# Radar v1

Личный AI-news радар: сбор источников → склейка в истории → ранжирование по профилю вкуса → утренний дайджест в мой Telegram-канал (`DIGEST_CHANNEL_ID`) с кнопками 👍/👎/⭐ → черновики постов по ⭐ в личку бота.

## Источник истины

- `docs/[spec.md](http://spec.md)` — полная спецификация. Расхождение между кодом и спекой решается в пользу спеки. Если спека неполна или противоречива — спроси, не додумывай.
- Строим строго по разделу «Порядок сборки»: один шаг за раз, в указанном порядке. Шаг закрыт, когда выполнен его критерий готовности.

## Стек (не менять без обсуждения)

- Python 3.12, uv, pydantic-settings; Telethon; feedparser + httpx; aiogram 3 (long polling); APScheduler; psycopg напрямую; Docker Compose.
- Postgres 18 + pgvector — сервис `postgres` в docker-compose (образ `pgvector/pgvector:pg18`), том для данных, ежедневный pg_dump; схема — `db/schema.sql`, дословно из спеки.
- LLM и эмбеддинги — OpenAI API (`OPENAI_API_KEY`); имена моделей только в [`config.py`](http://config.py) / `.env`: `EMBED_MODEL`, `CHEAP_MODEL`, `STRONG_MODEL`. Если модель эмбеддингов даёт не 1536 измерений — поменять `vector(1536)` в схеме.

## Правила

- Структура репозитория — из спеки: `adapters/ core/ bot/ db/ prompts/ jobs/`.
- Промпты — в `prompts/*.md` с `{placeholders}`, текст из спеки дословно.
- Все пороги — в [`config.py`](http://config.py), стартовые значения из таблицы «Пороги».
- Каждый job идемпотентен: повторный запуск ничего не дублирует.
- Секреты только в `.env` (есть `.env.example`); `.env` и `*.session` в `.gitignore`.
- Каждый запуск job пишет строку в `runs` со статистикой и стоимостью.
- Тесты минимум на: normalize (канонические URL), cluster (склейка), парсинг JSON-ответов LLM.
- Ничего сверх раздела «Что делает v1». Нет MCP, автопубликации, веб-UI, X как источника.

## Как работать

- Перед кодом по шагу: перечисли файлы, которые создашь или изменишь, и критерий готовности из спеки. Потом делай.
- После шага: как проверить руками — команда и ожидаемый результат.
- Если нужен мой ввод (код подтверждения Telegram, ключи, chat id) — остановись и скажи, что нужно.
- Один шаг — один коммит.
